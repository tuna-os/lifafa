Lifafa

Email client for the GNOME desktop. Version 1.47.1-tuna6. Source: https://github.com/tuna-os/lifafa.

Install, and get updates through flatpak update:

flatpak install --user https://tuna-os.github.io/lifafa/org.tunaos.lifafa.flatpakref

Or add the repository first:

flatpak remote-add --user --if-not-exists lifafa https://tuna-os.github.io/lifafa/org.tunaos.lifafa.flatpakrepo
flatpak install --user lifafa org.tunaos.lifafa
